# ThumbAI – Automated Thumbnail Analyzer & Builder

ThumbAI is an AI-powered web application that analyzes thumbnail quality and helps users create customized thumbnails.

## Features
- CTR Prediction
- Thumbnail Quality Analysis
- Text Detection using OCR
- Color Analysis
- Heatmap Analysis
- AI-Based Thumbnail Suggestions
- Custom Thumbnail Builder

## Development

Developed using HTML, CSS, and JavaScript for the frontend and Python Flask for backend processing. OpenCV and Pillow handle image analysis, Tesseract OCR performs text detection, and Google Gemini AI provides intelligent thumbnail insights.

## Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript
- Google Gemini AI
- OpenCV and Pillow
- Tesseract OCR
- MongoDB

## Objective

To automate thumbnail analysis and simplify thumbnail creation using AI and image processing techniques.
